# Mac에서 deid 편하게 쓰기

터미널을 몰라도 쓸 수 있도록 세 가지 방법을 준비했습니다.

1. **Finder 빠른 동작**: 파일을 오른쪽 클릭 → "개인정보 지우기"
2. **키보드 단축키**: 복사한 글이나 화면 캡처를 단축키 한 번으로 비식별화
3. **폴더 자동 감시**: `~/Deid/in` 폴더에 넣으면 `~/Deid/out`에 결과가 생김

기본으로 모든 처리는 이 Mac 안에서만 이루어집니다. 인터넷으로 보내지 않습니다. (설정에서 진료실 PC의 LLM
서버를 탐지에 연결했다면 원문이 그 PC까지 갑니다 — [../README.md의 진료실 LLM 서버 연결](../README.md#strata-등-진료실-llm-서버-연결))
전체 설명서(설치·업데이트·지우기, 설정 파일, 한계와 주의)는 [../README.md](../README.md)에 있습니다.

> **꼭 기억하세요.** deid는 개인정보가 새어 나갈 위험을 **줄여 줄 뿐, 없애 주지는 못합니다.** 공유하거나
> LLM에 붙여넣기 전에 결과를 **반드시 직접 읽어 보세요.** 손글씨, 특이한 이름, 별명, 사진 속 얼굴,
> `님`·`환자` 같은 말 없이 쓴 이름은 놓칠 수 있습니다. 무언가 남아 있었다면
> [개인정보가 남아 있으면](../README.md#9-1-개인정보가-남아-있으면)을 보세요.

## 0. 준비 (한 번만)

"터미널" 앱을 엽니다 (Spotlight: ⌘+스페이스 → "터미널"). 아래 줄을 한 줄씩 붙여넣고 Enter를 누릅니다.

```sh
# Homebrew가 없다면 먼저 https://brew.sh 의 설치 명령을 실행하세요.
brew install python@3.12 pipx tesseract tesseract-lang
pipx ensurepath
pipx install --python python3.12 ~/softkorea.github.io/tools/deid     # deid 폴더가 있는 실제 위치로 바꾸세요
```

(폴더 없이 인터넷 저장소에서 바로 설치하는 방법은 [../README.md](../README.md#2-설치--업데이트--지우기-m1-맥-기준)에 있습니다.)

터미널을 닫았다가 다시 열고 상태를 점검합니다.

```sh
deid doctor
```

`[XX]` 표시가 있으면 그 아래 `->` 줄의 안내대로 고치세요. `[!!]`는 확인이 필요한 항목, `[--]`는 선택
기능이라 없어도 됩니다.

설정 파일(선택): `deid init-config`를 실행하면 `~/.config/deid/config.toml`이 만들어집니다.
텍스트 편집기로 열어 맨 위의 `names = [ … ]` 목록 **안에** 직원 이름을, `allowlist = [ … ]` 안에 가리지 않을
낱말을 넣을 수 있습니다. 고친 뒤에는 `deid doctor`로 확인하세요 (오타가 있으면 deid는 처리하지 않고 멈추며
무엇이 틀렸는지 알려 줍니다).

**업데이트·지우기**는 [../README.md](../README.md#2-설치--업데이트--지우기-m1-맥-기준)의 순서를 따르세요.
특히 자동 감시(3번)를 켰다면, 업데이트한 뒤에는 `deid install-watch`를 다시 실행하고, 지울 때는
**프로그램보다 먼저** `deid install-watch --uninstall`과 `deid forget`을 실행합니다.

## 1. Finder 빠른 동작: 오른쪽 클릭 → "개인정보 지우기"

1. **Automator** 앱을 엽니다 (Spotlight에서 "Automator").
2. **새로운 문서** → **빠른 동작**을 고르고 **선택**.
3. 창 위쪽에서
   - "작업 흐름이 수신하는 현재 항목": **파일 또는 폴더**
   - "위치": **Finder**
4. 왼쪽 검색창에 **셸 스크립트 실행**을 입력하고, 나온 항목을 오른쪽 빈 곳으로 끌어다 놓습니다.
5. 셸 스크립트 칸에서
   - "셸": **/bin/zsh**
   - "입력 전달": **인수로**
   - 안의 내용을 모두 지우고 아래 **한 줄**을 붙여넣습니다.

   ```sh
   /usr/bin/env PATH=$HOME/.local/bin:/opt/homebrew/bin:$PATH deid file --notify "$@" 2>&1 | tail -20
   ```

6. **⌘S**로 저장하고 이름을 **개인정보 지우기**로 합니다.

**사용법**: Finder에서 파일(여러 개나 폴더도 됨)을 선택 → 오른쪽 클릭 → **빠른 동작** →
**개인정보 지우기**. 끝나면 알림이 뜨고, 결과는 원본 옆 **deid_out** 폴더에
`진료기록.deid.docx`처럼 저장됩니다. 원본은 바뀌지 않습니다.

- 지원 형식: 엑셀(xlsx, xlsm, csv, tsv), 워드(docx), 한글(hwpx), PDF, 이미지(png, jpg, heic 등), 텍스트(txt, md, json, html 등)
- 예전 형식(xls, doc, hwp)은 프로그램에서 "다른 이름으로 저장"으로 xlsx/docx/hwpx로 바꾼 뒤 처리하세요.
  pptx·key는 PDF로 내보낸 뒤, gif는 png로 바꾼 뒤 처리합니다. DICOM(.dcm)·메일·동영상은 처리하지 못합니다.
- **폴더**를 고르면 지원하지 않는 파일(dcm, gif …)은 결과 없이 건너뜁니다. 그런 파일이 원본 그대로
  공유되지 않도록 주의하세요.
- 엑셀의 그림·도형·피벗 테이블, PDF의 첨부 파일·전자서명처럼 검사할 수 없는 부분은 지우고 알려 줍니다.
- 파일 이름에 환자 이름이 있으면 결과 파일 이름에서도 `[이름1]`처럼 바뀝니다. 이름만 있는 파일 이름
  (`김민서.jpg`, `박서준_외래기록.docx`)도 이름으로 보고 바꿉니다. 드문 이름은 놓칠 수 있으니 공유 전에
  결과 파일 이름도 확인하세요.
- 알림에는 처리한 개수만 나옵니다 (잠금 화면에 이름이 보이지 않도록).

## 2. 키보드 단축키 (단축어 앱)

### 2-1. 처음 한 번: 스크립트 실행 허용

**단축어** 앱 → 메뉴 막대 **단축어 > 설정** → **고급** → **스크립트 실행 허용**을 켭니다.

### 2-2. "복사한 글 비식별화" 단축키 만들기

1. 단축어 앱에서 **+** (새 단축어).
2. 오른쪽 검색창에 **셸 스크립트 실행**을 입력해 추가합니다.
3. 셸은 **zsh**, 입력은 **입력 없음**으로 두고, 스크립트 칸에 아래 한 줄을 넣습니다.

   ```sh
   /usr/bin/env PATH=$HOME/.local/bin:/opt/homebrew/bin:$PATH LANG=en_US.UTF-8 deid clip --notify
   ```

   (또는 이 폴더의 스크립트를 부릅니다: `sh "$HOME/softkorea.github.io/tools/deid/macos/deid-clip.sh"`)
4. 단축어 이름을 **개인정보 지우고 복사**로 바꿉니다.
5. 오른쪽 위 **ⓘ(단축어 정보)** → **키보드 단축키 추가** → 예: **⌃⌥⌘C** (Control+Option+Command+C).

같은 방법으로 두 개를 더 만듭니다.

| 이름 | 스크립트 (끝부분만 다름) | 단축키 예 |
| --- | --- | --- |
| 가명 복원 | `... deid restore --notify` | ⌃⌥⌘R |
| 화면 캡처 가림 | `... deid shot --notify` (또는 `deid-shot.sh`) | ⇧⌥⌘4 (⌃ 없이) |

### 2-3. 쓰는 순서 (예: ChatGPT/Claude에 물어보기)

1. 전자의무기록(EMR)에서 글을 선택해 **⌘C**.
2. **⌃⌥⌘C** → 알림 "비식별화 완료: 이름 2, 전화번호 1". 이제 클립보드에는 `[이름1]`, `010-****-5678`처럼 바뀐 글만 있습니다.
3. LLM 입력창에 **⌘V**. 붙여넣기 전에 한 번 확인하세요.
4. LLM 답변을 복사(**⌘C**) → **⌃⌥⌘R** → `[이름1]`이 원래 이름으로 바뀐 답변이 클립보드에 들어갑니다 (이 Mac 안에서만).

- 클립보드에 **이미지**(캡처 등)가 있으면 글자를 읽어(OCR) 개인정보 부분을 검은 상자로 가린 이미지로 바꿉니다.
- 처리에 실패하면(설정 파일 오류, 읽을 수 없는 이미지 포함) 실수로 원문을 붙여넣지 않도록 **클립보드를 비우고**
  알림으로 알려 줍니다. Finder에서 복사한 **파일**도 처리할 수 없으므로 클립보드에서 비웁니다
  (파일은 1번의 빠른 동작을 쓰세요).
- `[이름1]`과 원래 이름의 대응표는 암호화되어 저장되며(열쇠는 macOS 키체인) **마지막으로 쓴 뒤 12시간**
  동안 쓰지 않으면 열쇠와 함께 지워집니다: 다음에 deid를 실행할 때, 또는 폴더 자동 감시(3번)나 브라우저
  화면(4번)이 켜져 있으면 곧바로. 그 전까지는 이 Mac에 암호화된 채 남아 있습니다.
- **자리를 비우거나 Mac을 다른 사람에게 넘기기 전에는** 터미널에서 `deid forget` (무엇을 지웠는지 보여 줍니다).
- 만료되거나 `deid forget`을 한 뒤에는 다시 `[이름1]`부터 시작합니다. 같은 LLM 대화창에서 이어 쓰면 다른
  두 사람이 같은 `[이름1]`로 섞일 수 있으니 **새 환자는 새 대화창에서** 시작하세요.
- LLM 답변 속 **링크(URL) 안의 `[이름1]`은 복원하지 않습니다** (복원한 글을 붙여넣는 순간 링크를 통해 이름이
  다른 서버로 전송될 수 있어서). 알림에 "링크 안의 가명 N개는 복원하지 않음"으로 알려 줍니다.
- 키체인이 잠겨 있으면 대응표를 지우지 않고 "키체인을 열 수 없어..." 오류를 냅니다. 키체인 잠금을 풀고 다시
  하세요 (그래도 안 되면 `deid forget`).

### 2-4. 화면 캡처 가림 (deid shot)

단축키(⇧⌥⌘4)를 누르면 십자 모양 커서가 나옵니다. 영역을 끌어 선택하면 개인정보를 가린 뒤
`~/Deid/out/shot-날짜-시각.png`로 저장하고 클립보드에도 넣습니다. **Esc**로 취소합니다.
창 하나는 `deid shot --window`, 전체 화면은 `deid shot --full`.

> 영역을 고를 때 **Control(⌃) 키를 누르고 있으면** macOS가 가리지 않은 원본 캡처를 클립보드로 보냅니다.
> deid는 이 경우도 알아채 가린 이미지로 바꾸지만(실패하면 클립보드를 비움), 그래서 단축키에 ⌃를 넣지 않는
> 것을 권합니다. 단축키를 누른 뒤에는 손을 떼고 영역을 끄세요.

처음 쓸 때 화면이 비어 있거나 바탕화면만 찍히면: **시스템 설정 > 개인정보 보호 및 보안 > 화면 기록**에서
**단축어**(터미널에서 쓴다면 **터미널**도)를 켜 주세요.

## 3. 폴더 자동 감시 (로그인하면 자동 시작)

터미널에서 한 번만 실행합니다.

```sh
sh ~/softkorea.github.io/tools/deid/macos/install_watch_agent.sh
# 또는 같은 일: deid install-watch
```

- `~/Deid/in` 폴더에 파일을 넣으면 몇 초 뒤 `~/Deid/out`에 결과가 생깁니다 (파일 복사가 끝나기를 기다렸다가 처리).
- 원본은 옮기거나 지우지 않습니다. 다 쓴 원본은 직접 지우세요.
- 파일을 고쳐서 다시 저장하면 다시 처리합니다.
- 처리할 때마다 알림이 뜹니다. 알림에는 파일 종류와 개수만 나옵니다 (끄려면 `deid install-watch --no-notify`로 다시 설치).
- 기록: `~/Library/Logs/deid-watch.log` (원본 파일 이름은 남기지 않고 비식별화된 결과 이름만 남깁니다.
  처리하지 못한 파일은 `김**_진***.png`처럼 가린 이름과 이유만 남깁니다).
- 지원하지 않는 파일(dcm, gif, eml …)은 기록도 결과도 없이 `in`에 그대로 남습니다.
- **설정 파일을 고치면** 켜 둔 감시도 다음 파일부터 새 설정을 씁니다. 고친 설정에 오류가 있으면 이전 설정으로
  계속 처리하고 기록 파일에 경고를 남기며, 알림("deid 감시: 설정 파일 오류")으로도 알려 줍니다. 고친 뒤에는
  `deid doctor`로 확인하세요. 설정 파일에 오류가 있는 동안은 설치 명령이 설치하지 않고 이유를 알려 줍니다.
- **deid를 업데이트한 뒤에는** 설치 명령을 한 번 더 실행하세요 (처음에 `--in`, `--out`, `--no-notify`를
  붙였다면 똑같이). 다시 실행하기 전까지는 예전 프로그램으로 돕니다.
- 감시 결과의 `[이름1]`은 대응표를 저장하지 않으므로 `deid restore`로 복원할 수 없습니다.
- `~/Deid`, `~/Deid/in`, `~/Deid/out`은 이 계정만 열 수 있게(권한 700) 만듭니다. 이 Mac의 다른 사용자
  계정은 원본을 읽을 수 없습니다. `deid doctor`가 권한이 느슨하면 알려 줍니다.
- 제거: `sh install_watch_agent.sh --uninstall` (또는 `deid install-watch --uninstall`). deid를 지울 때는
  **이것을 먼저** 하세요. 켜 둔 채 프로그램을 지우면 macOS가 없는 프로그램을 계속 다시 실행하려 합니다.
- 설정 내용만 보기: `deid install-watch --print`.
- 탐지에 진료실 LLM 서버를 연결했다면, 감시는 로그인할 때 시작되어 터미널의 환경변수를 모릅니다. API 키는
  `deid key set deid-strata`로 **키체인**에 넣고 설정에 `api_key_keychain = "deid-strata"`를 적으세요. 서버가 꺼져
  있어 처리하지 못한 파일은 기록에 `FAIL`로 남으니, 서버를 고친 뒤 그 파일을 다시 저장하거나 다시 넣으세요.

> 감시 폴더를 **바탕화면/문서/다운로드** 안에 두지 마세요. macOS 보호 폴더라서 백그라운드 작업이
> 접근 권한 문제로 멈출 수 있습니다. 기본값 `~/Deid`를 쓰는 것이 가장 간단합니다.

터미널에서 잠깐만 감시하려면: `deid watch ~/Deid/in ~/Deid/out` (Ctrl-C로 종료).

## 4. 브라우저 화면 (deid serve)

```sh
deid serve
```

브라우저가 열리며 글을 붙여넣어 **비식별화 / 원래대로 복원 / 복사**를 하거나 파일을 끌어다 놓으면 결과
파일이 자동으로 다운로드됩니다. 이 Mac(127.0.0.1)에서만 열리고, 주소에 들어 있는 비밀 토큰이 없으면
접속되지 않습니다. 끝내려면 터미널에서 Ctrl-C. 설정 파일을 고치면 다음 요청부터 새 설정을 쓰고, deid를
업데이트했다면 Ctrl-C로 끈 뒤 다시 실행하세요. 탐지에 진료실 LLM 서버를 연결해 두었다면 화면 맨 위에 원문이 그
서버로 전송된다는 경고가 나옵니다.

## 5. 보관함 파일(`--vault`)을 빠른 동작·단축어에서 쓰기 (선택)

여러 날에 걸쳐 나눠 처리해도 같은 사람에게 같은 가명을 주려면 `--vault 보관함파일`을 씁니다. 보관함은
암호로 잠깁니다. 터미널에서는 암호를 물어보지만, 빠른 동작·단축어에는 암호를 입력할 창이 없어서
`DEID_VAULT_PASS` 환경변수가 없으면 오류로 멈춥니다. 암호를 스크립트에 그대로 적지 말고 **키체인에 넣어 두고
꺼내 쓰세요.**

**① 한 번만: 보관함 암호를 키체인에 넣기** (터미널, 암호를 두 번 묻습니다)

```sh
security add-generic-password -a "$USER" -s deid-vault -w
```

**② 빠른 동작(1번)의 셸 스크립트를 아래 세 줄로**

```sh
export PATH="$HOME/.local/bin:/opt/homebrew/bin:$PATH"
export DEID_VAULT_PASS="$(security find-generic-password -a "$USER" -s deid-vault -w)"
deid file --vault "$HOME/deid.vault" --notify "$@" 2>&1 | tail -20
```

**③ 이 보관함으로 만든 결과의 LLM 답변 복원** (단축어, 2-2와 같은 방법)

```sh
export PATH="$HOME/.local/bin:/opt/homebrew/bin:$PATH" LANG=en_US.UTF-8
export DEID_VAULT_PASS="$(security find-generic-password -a "$USER" -s deid-vault -w)"
deid restore --vault "$HOME/deid.vault" --notify
```

터미널에서는 `deid restore --vault ~/deid.vault`(클립보드), 파일로 저장한 답변은
`deid text --restore --vault ~/deid.vault < 답변.txt > 복원.txt`.

- 처음에 키체인 접근을 묻는 창이 뜨면 **항상 허용**을 누르세요.
- 키체인에 넣은 암호가 곧 보관함 암호입니다. **암호를 잊거나 키체인 항목을 지우면 그 보관함으로는 복원할 수
  없습니다.** 되살릴 방법이 없습니다.
- `--vault`로 만든 가명은 세션 보관함과 따로라서, `--vault` 없는 ⌃⌥⌘R(2번)로는 복원되지 않습니다.
- 보관함 파일은 결과물과 **함께 보내지 마세요** (가명을 원래 이름으로 되돌리는 열쇠입니다).
- 다 쓴 뒤 키체인 항목 지우기: `security delete-generic-password -a "$USER" -s deid-vault`

## 6. (선택) 로컬 LLM으로 한 번 더 점검

[Ollama](https://ollama.com)를 설치하고 모델을 받은 뒤(16GB Mac이면 `gemma3:4b` 정도가 알맞습니다):

```sh
ollama pull gemma3:4b
deid check deid_out/진료기록.deid.txt
```

LLM이 "아직 남아 있는 것 같은" 개인정보를 화면에만 보여줍니다 (파일로 저장하지 않음). LLM도 틀릴 수
있으니 참고용입니다. 사람의 확인을 대신하지 못합니다.

Ollama 대신 진료실 PC의 LLM 서버(Strata 등)로 점검하거나, 그 서버를 탐지에 쓰는 방법은
[../README.md의 진료실 LLM 서버 연결](../README.md#strata-등-진료실-llm-서버-연결)에 있습니다. 단축키(⌃⌥⌘C)나
빠른 동작에서도 같은 설정이 쓰이고, 서버 문제로 처리하지 못하면 클립보드를 비우고 알림으로 알려 줍니다.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| `deid: command not found` | `pipx ensurepath` 후 터미널 다시 열기. 빠른 동작/단축어에는 위의 `PATH=...`가 들어간 줄을 그대로 쓰세요. |
| 한글이 `???`로 깨짐 | 스크립트 앞에 `LANG=en_US.UTF-8`을 붙이세요 (위 예시에 포함). |
| 이미지/스캔 PDF에서 아무것도 못 찾음 | `deid doctor`에서 OCR 항목 확인: `brew install tesseract tesseract-lang` |
| 추가 기능 설치 안내가 나옴 | `deid doctor`가 알려 주는 명령(`pipx inject deid-kit ...`)을 그대로 실행하세요. 그냥 `pip install`은 deid가 설치된 곳에 닿지 않습니다. |
| "키체인을 열 수 없어..." | 키체인 접근 앱에서 로그인 키체인 잠금을 풀고 다시 시도. 계속되면 `deid forget` |
| 단축키를 눌러도 반응 없음 | 단축어 > 설정 > 고급 > 스크립트 실행 허용, 그리고 다른 앱과 단축키가 겹치지 않는지 확인 |
| 복원이 안 됨 | 마지막 사용 후 12시간이 지나 세션이 만료(열쇠와 함께 삭제)되었거나 `deid forget`을 실행한 경우, 또는 `--vault`로 만든 결과인데 `--vault` 없이 복원한 경우입니다. |
| "보관함 파일(--vault)의 암호를 물어볼 터미널 창이 없습니다" | 빠른 동작·단축어에서 `--vault`를 쓸 때는 5번처럼 `DEID_VAULT_PASS`를 넣으세요. |
| 빠른 동작·단축어가 "설정 파일 오류"로 실패 | 설정 파일에 오타가 있어 처리하지 않고 멈춘 것입니다. 터미널에서 `deid doctor`로 무엇이 틀렸는지 확인하세요. |
| 설정을 바꿨는데 자동 감시에 반영이 안 됨 | 고친 설정에 오류가 있어 이전 설정으로 돌고 있을 수 있습니다. `deid doctor`와 `~/Library/Logs/deid-watch.log` 확인 |
| 무언가 가려지지 않고 남아 있었음 | [../README.md의 "개인정보가 남아 있으면"](../README.md#9-1-개인정보가-남아-있으면) 순서대로 (실제 기록으로 제보하지 마세요) |
| 업데이트했는데 그대로인 것 같음 | `deid --version` 확인. 자동 감시는 설치 명령 다시 실행, `deid serve`는 다시 시작 |
| "LLM 서버 문제로 처리하지 못해 클립보드를 비웠습니다" | 진료실 LLM 서버가 꺼져 있거나 API 키가 틀렸습니다. 터미널에서 `deid doctor`의 `LLM 서버` 줄을 확인하세요 |

이 폴더의 파일:

- `deid-clip.sh`, `deid-shot.sh` — 단축어/단축키용 래퍼 (PATH와 한글 설정을 채우고 알림 표시)
- `install_watch_agent.sh` — 폴더 자동 감시 설치/제거 (`--uninstall`)
